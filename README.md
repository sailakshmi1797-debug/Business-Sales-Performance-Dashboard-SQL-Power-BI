Sales Performance & Revenue Insights Dashboard

📌 Project Overview

This project focuses on analyzing retail sales data to uncover trends, track Key Performance Indicators (KPIs), and identify growth opportunities. I used SQL to aggregate transaction data and Power BI to build an interactive suite of reports for stakeholders.

📊 Business Questions Answered

1.Which product categories drive the highest profit margins?

2.How do sales compare Year-over-Year (YoY) and Month-over-Month (MoM)?

3.Which geographic regions are underperforming against sales targets?

4.Who are our Top 10 customers by total revenue?

🛠️ Tech Stack

1.Database: SQL (PostgreSQL/MySQL)

2.BI Tool: Power BI

3.Data Modeling: Star Schema (Fact and Dimension tables)

4.Calculations: DAX (Time Intelligence functions)

⚙️ The Pipeline

1.Data Extraction: Sourced retail transaction data.

2.SQL Analysis: Performed deep-dive queries to calculate profit margins and rolling averages.

3.Power BI Modeling: Created a Calendar table to enable advanced Time Intelligence.

4.Visual Storytelling: Designed a multi-page report focusing on Sales Overview, Regional Performance, and Product Deep-dives.
